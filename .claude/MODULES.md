# Modules

Registry of module IDs used by `.claude/maps/`, `.claude/decisions/` and `MODULE:` Decision blocks.

## Structural modules

- `engine` — CPU engine: `core/engine/` except the page table and TLB fill/flush (Tier 0 interpreter `interp.c`/`simd.c`/`atomic.c`/`native.c`/`cpu.c`, Tier 1 translator `dbt.c`/`emit.h`, `features.c`, `guard.c`, `include/appine/engine.h`, Rust bindings `src/lib.rs`) plus `tests/lockstep`; instruction execution, translation, code cache and sharing, FP state, CPU features, host fault guard.
- `kernel/process` — processes, threads and scheduling: `core/kernel/src/task.rs`, `process.rs`, `kernel.rs` (BKL, `Cx`, wake-ups), `cell.rs`, `syscall/proc.rs`, `syscall/fast.rs`, `futex.rs`, `loader.rs`, `machine.rs` (timer thread, boot/shutdown), `itimer.rs`, `posix_timer.rs`, `loadavg.rs`, `inittab.rs`, `syscall/sched.rs`, `pidns.rs`, `nsproxy.rs`, `syscall/ns.rs`, user namespaces in `cred.rs`; task lifecycle, execve and the ELF loader, BKL and fast path, waiting and futexes, timers, PID 1, namespaces.
- `kernel/signal` — signals, ptrace and the user-visible ABI: `core/kernel/src/signal.rs`, `syscall/sig.rs`, `vdso.rs`, `ptrace.rs`, `syscall/ptrace.rs`, `coredump.rs`, `klog.rs`, signalfd, and in `syscall/misc.rs` uname/syslog/adjtimex/clock setting/restart_syscall; signal generation and delivery, frames and sigreturn, fault-to-signal mapping, the vDSO, ptrace, core dumps, the kernel log, the 6.1 ABI contract and ENOSYS policy.
- `kernel/store` — the rootfs inode store: `core/kernel/src/vfs/store.rs`, `vfs/import.rs`, `vfs/browse.rs` and the host wrappers in `lib.rs` (`import_rootfs`, `sync_store`, `browse`, `browse_changing`, `write_file`, `read_file`); SQLite namespace and objects, deferred commits and power-loss ordering, the reaper and checkpoints, boot cleanup, the metadata cache, sharing with the DocumentsProvider, rootfs import, the host browse API.
- `kernel/vfs` — the VFS layer: `core/kernel/src/vfs/mod.rs`, `vfs/dev.rs`, `fd.rs`, `pipe.rs`, `locks.rs`, `syscall/fs.rs`, `syscall/mount.rs`, `syscall/xattr.rs`, `syscall/lease.rs`, `syscall/inotify.rs`, `syscall/timerfd.rs`; mount-aware nodes and path resolution (openat2 `RESOLVE_*`, the no-BKL `Cached` resolver), the mount table, mount syscalls and mount-namespace tables, tmpfs instances, fd tables and open files, file I/O and metadata syscalls, xattrs, pipes and FIFOs, locks and leases, device nodes, inotify.
- `kernel/procfs` — synthetic filesystems and cgroups: `core/kernel/src/pseudo.rs`, `cgroup.rs`, `bpf.rs`, `syscall/bpf.rs`; procfs (per-process and system-wide files, `/proc/sys` sysctls and their namespace scoping, `/proc/<pid>/net`), sysfs, devpts and nsfs nodes, the mqueue filesystem's nodes, the cgroup v2 tree with migration and enforced limits, and the bpf(2) subset for cgroup device programs.
- `kernel/tty` — terminals: `core/kernel/src/tty.rs`, `syscall/tty.rs`, `terminal.rs`; in-process PTY pairs (allocation, opening, hangup and vhangup), the line discipline and termios/termios2, packet mode, job control (controlling terminals, foreground groups, background checks, terminal signals), and the host console used by the app's tabs and the `appine-run` bridge.
- `kernel/net` — the socket layer for internet and netlink sockets: `core/kernel/src/net.rs`, `syscall/net.rs`, `rawicmp.rs`, `route.rs`, `portmap.rs`, `traffic.rs`, `origdst.rs`; TCP/UDP passthrough to host sockets with emulated blocking and options, raw ICMP on ping sockets, in-process netlink and the routing table, the DNS stub, low-port mapping, traffic counters, `SO_ORIGINAL_DST` and `SO_MARK`.
- `kernel/netns` — network namespaces without a network stack: `core/kernel/src/netns.rs`, `netdev.rs`, `nft.rs`, `forward.rs`, `netconf.rs`; namespaces as host loopback blocks with address translation, namespace ports and listeners, virtual devices (bridge, veth, dummy) with addresses, routes and sysctls, nftables (ruleset over `NETLINK_NETFILTER` and evaluation at connect/sendto), and forwarding of outside connections to published ports.
- `kernel/unix` — AF_UNIX sockets emulated in process: `core/kernel/src/unix.rs`, `syscall/unix.rs`; stream, datagram and seqpacket sockets, path and abstract names, connection lifecycle, data transfer with `SCM_RIGHTS`/`SCM_CREDENTIALS`/`SO_PEERCRED`, readiness, `/proc/net/unix`, and the garbage collector for in-flight cycles.
- `kernel/poll` — I/O multiplexing: `core/kernel/src/syscall/poll.rs`; the shared readiness model (`readiness`, `arrivals`, `wake_objects`), ppoll and pselect6, epoll (edge triggering, nesting, ONESHOT, EXCLUSIVE gates), eventfd2, and signal-driven I/O checked by the timer thread.
- `kernel/mm` — guest memory (soft-MMU): `core/kernel/src/mm.rs`, `core/kernel/src/syscall/mem.rs`, the page table in `core/engine/src/c/mmu.c` and the `Mmu` wrapper, the software TLB in `core/engine/src/c/cpu.c` and `internal.h`, and the page-fault branch of the task run loop; VMAs, host backing, demand paging, TLB shootdown, fork copy-on-write, and memory introspection.
